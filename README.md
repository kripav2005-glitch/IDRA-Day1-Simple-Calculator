# IDRA Day 1 - Simple Calculator

## Assignment
Simple Calculator – Day 1

## Organization
India Data Research Academy (IDRA)

## Description
This project is a simple calculator created using Python.

The program accepts two numbers from the user and performs the following arithmetic operations:

- Addition
- Subtraction
- Multiplication
- Division
- Floor Division
- Modulus
- Exponentiation

## Python Concepts Used

- Variables
- User input
- Numeric data types
- Arithmetic operators
- Formatted print statements

## File

IDRA_Day1_Simple_Calculator.ipynb

## Conclusion

The Simple Calculator demonstrates the use of basic Python arithmetic operators and user input.
